Project Overview
An interactive Power BI dashboard analyzing health insurance coverage across the U.S. population, broken down by age, sex, race/ethnicity, income, education, employment, disability status, and poverty level. Built to demonstrate Power Query ETL, DAX measure design, and demographic KPI reporting.

Data Source: U.S. Census Bureau, American Community Survey (ACS) 1-Year Estimates, Table S2701 - "Selected Characteristics of Health Insurance Coverage in the United States," 2024 vintage. data.census.gov
